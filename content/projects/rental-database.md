A web application for managing and browsing rental property listings in Kingston, built database-first.

## Design

The schema began as an entity-relationship diagram, then was implemented as a **MySQL** database. **PHP** handles server-side scripting behind an **Apache** web server, with an HTML/CSS front end for browsing and managing listings.
